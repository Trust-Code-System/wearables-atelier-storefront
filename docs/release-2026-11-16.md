# Storefront 0.1.1 — pre-release verification

Date: 16 November 2026. Branch: `codex/storefront-release-20261116`. Code checked: `b7bfec4`, based on the latest `origin/main` search-visibility changes.

## Changes

- The brand intro is present in the initial homepage HTML. Its reveal begins after hydration, so slow scripts and repeat visits do not show the homepage first. Skip and no-JavaScript access remain available.
- The jewellery edit uses the original look-05 necklace-and-earrings photograph while products load or when no jewellery products are available. The photo links to the jewellery collection; real product cards remain when the API returns them.
- Shop sort, size and price changes stay consistent with the URL and browser navigation, including changes within the same category.
- Account, bag and checkout failures give retry or contact guidance. A failed bag update can be followed by a read to confirm the server state without repeating the failed write.
- Latest `main` SEO work remains intact: the homepage server wrapper and `home-client.tsx` split, page metadata, structured data, robots and sitemaps. Next.js remains pinned to `16.4.2`; application version is `0.1.1`.

## Release boundaries

At the time this record was written, public production deployment and live smoke verification were pending. Preview success and a local production build are not evidence that the release is serving the public domain.

Generated `.next-*` build directories are ignored and are not part of the release. Existing design context was restored and the new intro/photo preferences appended. Historical QA reports remain dated evidence and do not supersede this record.
