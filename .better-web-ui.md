## Design Context

### Users
Wearables Atelier customers browsing clothing and jewellery, choosing numbered sizes and shopping in NGN or USD. The admin console is now a separate project and repository.

### Brand Personality
Premium, modern, personal and readable. Use the original Wearables by Ashabi logo, supplied Nigerian occasionwear imagery, rounded panels and purposeful gentle motion.

### Aesthetic Direction
The storefront uses bone white and olive, Manrope text, sparse Bodoni Moda italic accents, photographic campaigns and category-specific collection introductions. The original ObsidianUI dashboard choice belongs to the separate admin project; its source is absent here.

### Implementation Defaults
Preserve Next.js 16.4 App Router, React 19, Tailwind 4, Base UI primitives, Motion, Lenis and native React form state. Catalog/settings are read-only browser prototypes; customer cart and demo checkout state remain local. Shared backend integration is explicitly deferred. Follow version-matched Next.js docs in node_modules/next/dist/docs.

### Design Principles
- Preserve the brand identity, photographic hierarchy and rounded-edge direction.
- Keep existing customer commerce interactions functional.
- Keep admin routes, dashboard source, editing actions and seeded admin orders out of this project.
- Preserve keyboard controls, visible focus, reduced motion, and mobile access.
